# قوانین بین‌المللی

نسخهٔ دیجیتال سند «قوانین بین‌المللی» (اینترنشنال) — متن کامل، با فهرست مطالب، جستجوی متنی، لینک مستقیم هر ماده و دکمهٔ کپی.

- **سند قوانین:** <https://godde3s.github.io/International/rules.html>
- **کانال تلگرام:** <https://t.me/Ghavanin_internationaL>

## ساختار

```
index.html   صفحهٔ خانه (فهرست انواع کل، بانیان سند، اعضای تیم)
rules.html   متن کامل قوانین در ۱۳ ماده با فهرست چسبان و جستجو
404.html     برگهٔ «یافت نشد»
assets/      استایل و رفتار صفحه (بدون هیچ فریم‌ورک)
DESIGN.md    توضیح تصمیم‌های طراحی و دلیل هر کدام
```

## ویژگی‌ها

- بدون قالب و بدون کتابخانه؛ HTML و CSS و JS دست‌نویس
- تم تیرهٔ «آرشیو اسناد» به‌صورت پیش‌فرض + تم روشن «روزنامهٔ رسمی» با کلید تغییر و ذخیره در مرورگر
- جستجوی زنده در متن سند (ی/ك عربی، نیم‌فاصله و رقم فارسی/لاتین همه پوشش داده می‌شوند؛ کلید میان‌بر `/`)
- کپی متن هر ماده و کپی لینک مستقیم آن برای ارجاع در چت
- واکنش‌گرا، کنتراست AA در هر دو تم، پشتیبانی از `prefers-reduced-motion`، و استایل چاپ تمیز برای نسخهٔ کاغذی

## متن سند

متن قوانین عیناً و بدون تغییر از نسخهٔ رسمی کانال آورده شده است؛ فقط ظاهر و ابزارهای خواندن تازه شده.
