# قوانین بین‌المللی

نسخهٔ دیجیتال سند «قوانین بین‌المللی» (اینترنشنال) — متن کامل، با جستجوی متنی، لینک مستقیم هر ماده و دکمهٔ کپی؛ با زبان بصری اپلیکیشن‌های iOS.

- **سند قوانین:** <https://godde3s.github.io/International/rules.html>
- **کانال تلگرام:** <https://t.me/Ghavanin_internationaL>

## ساختار

```
index.html            صفحهٔ خانه — فقط دو دکمه iOS Version و Android Version (بدون اسکرول)
ios/index.html        نسخهٔ iOS — گفت‌وگو به سبک Messages آیفون (۱۳ ماده، لینک مستقیم هر پیام #/m{id}/b{index}) + PWA خودش (manifest.webmanifest و sw.js)
android/index.html    نسخهٔ اندروید ۱۷ — گفت‌وگو به سبک Google Messages با Material 3 + PWA خودش (manifest.webmanifest و sw.js)
sw.js                 سرویس‌ورکر قدیمی صفحهٔ اصلی — فقط کش قدیمی را پاک و خودش را حذف می‌کند
icons/                آیکون اپ (icon-192.png و icon-512.png)
rules.html            متن کامل قوانین در ۱۳ ماده با جستجو و فهرست تراشه‌ای
404.html              برگهٔ «یافت نشد»
assets/               استایل و رفتار صفحهٔ rules.html (بدون هیچ فریم‌ورک)
DESIGN.md             توضیح تصمیم‌های طراحی و دلیل هر کدام
```

## ویژگی‌ها

- بدون قالب و بدون کتابخانه؛ HTML و CSS و JS دست‌نویس (کل بار صفحه بدون فونت، حدود ۸۸ کیلوبایت)
- زبان بصری اپلیکیشن‌های بومی iOS: عنوان بزرگ، کارت گروه‌شده، نوار شفاف مات، نوار تب پایین و تراشه‌های افقی
- پالت سیاه + طوسی + نارنجی (رنگ‌های سیستمی iOS) با تم تیرهٔ پیش‌فرض و تم روشنِ ذخیره‌شونده
- جستجوی زنده در متن سند (ی/ك عربی، نیم‌فاصله و رقم فارسی/لاتین همه پوشش داده می‌شوند؛ کلید میان‌بر `/`)
- فهرست تراشه‌ای چسبان با نشان‌گر خودکار مادهٔ فعال هنگام اسکرول
- کپی متن هر ماده و کپی لینک مستقیم آن با اطلاع HUD مانند iOS
- واکنش‌گرا از ۳۲۰px تا دسکتاپ، کنتراست AA در هر دو تم، پشتیبانی از `prefers-reduced-motion` و استایل چاپ تمیز

## متن سند

متن قوانین عیناً و بدون تغییر از نسخهٔ رسمی کانال آورده شده است؛ فقط ظاهر و ابزارهای خواندن تازه شده.
